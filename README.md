# Документация для лабораторной работы (geometic_lib)

## 1. Общее описание решения
Данная библиотека предназначена для проведения **геометрических расчетов**. Она автоматизирует процесс вычисления площади и периметра плоских геометрических фигур, таких как **квадрат** и **треугольник**.

> [!NOTE]
> Скрипты работают как с целыми числами, так и с дробными (через точку). На выходе получаем точный результат вычислений.

---

## 2. Описание функций с примерами вызова

### Модуль `square.py` (Квадрат)

#### Функция `area(a)`
* **Что делает:** Считает площадь квадрата, зная длину его стороны.
* **Параметры:** `a` — длина стороны (число).
* **Что возвращает:** Значение площади фигур.

*Пример запуска кода:*
```python
from square import area

res = area(5)
print("Площадь:", res)  # Выведет: 25
```

#### Функция `perimeter(a)`
* **Что делает:** Находит периметр квадрата по его стороне.
* **Параметры:** `a` — сторона квадрата (число).
* **Что возвращает:** Сумму длин всех четырех сторон.

*Пример запуска кода:*
```python
from square import perimeter

res = perimeter(5)
print("Периметр:", res)  # Выведет: 20
```

---

### Модуль `triangle.py` (Треугольник)

#### Функция `area(a, h)`
* **Что делает:** Находит площадь треугольника. Перемножает основание на высоту и делит пополам.
* **Параметры:** 
  * `a` — длина основания.
  * `h` — высота, проведенная к этому основанию.
* **Что возвращает:** Площадь треугольника (всегда дробное число).

*Пример запуска кода:*
```python
from triangle import area

res = area(4, 5)
print("Площадь треугольника:", res)  # Выведет: 10.0
```

#### Функция `perimeter(a, b, c)`
* **What делает:** Считает периметр треугольника, просто складывая три его стороны.
* **Параметры:** `a`, `b`, `c` — длины трех сторон.
* **Что возвращает:** Периметр фигуры.

*Пример запуска кода:*
```python
from triangle import perimeter

res = perimeter(3, 4, 5)
print("Периметр треугольника:", res)  # Выведет: 12
```
